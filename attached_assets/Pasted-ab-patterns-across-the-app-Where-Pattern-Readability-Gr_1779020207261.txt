Root cause of the popup tab problem
The tab bar for Overview / Clinical / Notes / Actions / Billing is embedded inside the dark green gradient header (from-primary/90 via-primary to-accent/80). This causes two issues:
1. Active tab uses a white bottom border (border-b-2 border-white) — a thin white line on dark green is barely visible and hard to spot quickly.
2. Inactive tabs are text-white/55 — 55% opacity white on a dark colour is too dim to read comfortably.
3. The tab bar has no visual container of its own — it blends into the header visually, so you don't immediately perceive it as a navigation area.
4. A bottom underline indicator works well on a light background (GitHub, Linear, Stripe all use this), but on a dark coloured gradient it loses the contrast needed to communicate "this is selected."

Proposed fix
Move the tab strip out of the dark header into its own neutral strip immediately below it. This is a single-component change — only the booking popup modal in ClinicDashboard.tsx.
Result would look like:
┌──────────────────────────────────────┐ ← dark green header (patient name,
│ 👤 Patient Name REF-0001 │ badges, appointment time — unchanged)
│ ✓ Admin Confirmed │
│ 📅 Mon, 19 May 2026 🕐 10:00 AM │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐ ← NEW: neutral tab strip (bg-card)
│ Overview Clinical Notes Actions Billing │
│ ───────── │ ← active: primary coloured underline
└──────────────────────────────────────┘
│ tab content... │

Active tab → text-primary border-b-2 border-primary on white/card background = crisp and immediately clear Inactive tab → text-muted-foreground = readable but subdued Hover → hover:text-foreground hover:border-muted-foreground/30 = responsive feedback
This matches exactly how GitHub, Linear, and Stripe handle modal/detail tabs. Underline tabs on a light background is universally recognisable.
