Context (for the Agent)
Patient card currently has tabs: Overview, Clinical, Notes, Actions, Billing.
Clinical Tab: Doctor adds prescriptions (medicine, dosage, duration, qty).
Billing Tab: Admin manually creates bills (consultation, procedures, consumables).
Problem: Billing and prescriptions are disconnected → duplication, mismatch, manual effort.
New Requirement:
Add Pharmacy Stock Catalog as a side nav item in the clinic dashboard.
Optimize Billing UI with consolidated preview, prescription auto‑loading, and market‑standard controls.
🧩 Step‑by‑Step Flow
1. Pharmacy Stock Catalog (Side Nav Item)
Side Nav Item: “Pharmacy Stock Catalog” → opens management screen.
Admin UI:
Add Medicine Form: Name, Dosage, Unit Price, Available Qty, Expiry.
List View: Table of medicines with Edit/Delete/Update Stock.
Database Schema:
sql
CREATE TABLE pharmacy_stock (
  id SERIAL PRIMARY KEY,
  medicine_name TEXT NOT NULL,
  dosage TEXT,
  unit_price NUMERIC NOT NULL,
  available_qty INT DEFAULT 0,
  expiry_date DATE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
✅ This catalog becomes the single source of truth for medicine pricing.
2. Prescription Entry (Clinical Tab)
Doctor adds prescription: medicine, dosage, qty, duration.
Prescription saved in prescriptions table linked to patient + visit.
✅ Structured data ready for billing.
3. Bill Drafting (Billing Tab)
Admin opens Billing Tab → new Bill ID created (status = draft).
Manual items can be added (consultation, procedures, consumables).
Each row: item name, qty, unit price, discount, total.
4. Prescription → Billing Integration
Add button in Billing Tab: “Load Prescription Items”.
On click:
Fetch prescription from Clinical Tab.
For each medicine:
Check pharmacy_stock for matching name/dosage.
If found → auto‑populate unit price + calculate total.
If not found → admin enters price manually, with option to “Add to Catalog.”
✅ Ensures consistency between doctor’s prescription and billing.
5. Auto‑Populate Medicine Amount
Formula:
Total
=
Quantity
×
Unit Price
Discounts applied automatically.
✅ Eliminates manual calculation errors.
6. Cash Payment Handling
Inside each bill card → Mark as Paid → Cash.
Admin enters: amount received, cashier ID, date/time, notes.
System updates bill status → paid.
Log entry created in payment_logs.
✅ Matches industry standard for cash billing.
7. Digital Bill Generation
Once bill marked paid:
System generates PDF invoice (itemized rows + prescription meds).
Stores file in secure storage.
Creates time‑limited download link.
✅ Patient record updated with invoice_url.
8. Patient Notification
Patient receives WhatsApp/email:
“Your bill for Visit #123 is paid. Download your invoice here: [secure link]”.
✅ Builds trust and transparency.
🧩 Optimized Billing UI (Market Standard)
Top Section → Consolidated Bill Preview
Shows skeleton of PDF invoice:
Patient info, visit ID, date.
Itemized rows (manual + prescription).
Subtotal, discount, tax, total.
Payment status.
Controls:
Download Consolidated PDF (primary).
Print.
Share (WhatsApp/Email).
✅ Patients/admins immediately see the “final bill look.”
Middle Section → Bill Cards
Each bill shown as a card/list row:
Bill ID, Date, Amount, Payment Method.
Actions: Mark Paid, View PDF, Delete.
Grouping: Bills grouped by visit/date.
Consolidated Summary: At top of list → “2 bills · ₹300 Consolidated.”
✅ Clear separation between consolidated view and individual bills.
Bottom Section → Confirmation
Green confirmation bar → “Confirmed by Dr. John.”
Red cancel button → cancel visit/billing if needed.
✅ Matches clinical workflow.
History Integration
Billing Tab shows:
Current Bill (Draft).
Past Bills (last 6 months) → with status, amount, download link.
Past Prescriptions (last 6 months) → with “Load Prescription Items” option.
✅ Industry standard for continuity and audit.
Error Handling & Audit
If bill marked paid but invoice not generated → log error, retry option.
Daily reconciliation job ensures every paid bill has valid invoice_url.
Audit trail: every action logged (prescription import, bill draft, payment, invoice generation).
✅ Ensures compliance and debugging.
