Analysis: Website Panel Mobile Issues vs. Design Doc
What the screenshots show
Screenshot 1 (panel header):
* The "Clinic Website" title + 5-line description + two buttons are all in a single flex justify-between row — the description wraps to 5 lines while the button group simultaneously overflows the right edge (you can see "Save Websit…" clipped off screen)
* The "Preview" button shows the desktop version (eye + external-link icons) instead of the mobile one (phone icon). This points to a viewport width issue — the Replit in-app preview pane renders at ≥640px wide on the device you're testing from, so the sm: breakpoints fire in "desktop" mode even though you're on a phone
* The "Website Structure" header info badge text and "Open live page" link are both text-[10px] — visible as very small text in the screenshot
Screenshot 2 (Stats section):
* The 2×2 stats preview grid is working correctly ✅
* The stats editor inputs look fine — the truncated "Tooth Extractior" is just normal input field clipping, not a bug
* The section label bar "STATS BAR" + "updates as you type" are in text-[10px] — design doc violation
