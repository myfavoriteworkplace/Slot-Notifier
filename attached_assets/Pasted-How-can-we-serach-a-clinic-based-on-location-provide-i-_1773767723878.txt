If you’ve already saved your clinics in a database, the way to implement search by location depends on how you store the location data. Let me break it down step‑by‑step:
🗂️ Step 1: Store Location Properly
Option A: City/Area fields  
Save city, state, pincode as separate columns.
Option B: Coordinates (latitude/longitude)  
Save lat and lng for each clinic. This allows precise distance‑based searches.
🛠️ Step 2: Query by Location
If you store city/pincode
sql
SELECT * 
FROM clinics 
WHERE city = 'Ernakulam';
Or partial match:
sql
SELECT * 
FROM clinics 
WHERE city ILIKE '%kochi%';
If you store latitude/longitude
You can calculate distance using the Haversine formula:
sql
SELECT id, name, 
       (6371 * acos(
           cos(radians(:user_lat)) * cos(radians(lat)) *
           cos(radians(lng) - radians(:user_lng)) +
           sin(radians(:user_lat)) * sin(radians(lat))
       )) AS distance_km
FROM clinics
HAVING distance_km < 10
ORDER BY distance_km;
Replace :user_lat and :user_lng with the user’s current coordinates.
6371 is Earth’s radius in km.
This query finds clinics within 10 km of the user.
🛠️ Step 3: Backend Implementation (Node.js + pg)
Example with pg library:
js
import { Pool } from 'pg';

const pool = new Pool({ connectionString: process.env.DATABASE_URL });

async function findClinicsNearby(lat, lng, radiusKm = 10) {
  const query = `
    SELECT id, name, 
           (6371 * acos(
               cos(radians($1)) * cos(radians(lat)) *
               cos(radians(lng) - radians($2)) +
               sin(radians($1)) * sin(radians(lat))
           )) AS distance_km
    FROM clinics
    HAVING distance_km < $3
    ORDER BY distance_km;
  `;
  const res = await pool.query(query, [lat, lng, radiusKm]);
  return res.rows;
}
