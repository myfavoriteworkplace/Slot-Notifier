Detailed Specification of Proposed Changes
1. Header Zone & Profile Alignment
* Remove Explicit Email Fields: Long strings like creditsmanager.arun@gmail.com clutter the UI layout. Instruct your agent to hide this behind a hover tooltip or pull it into a dedicated detail drawer.
* Format Demographics: Group unstructured data points like 30y and F into a clean metadata sequence: [Phone Number] • [Age / Gender].
* Unify Status Stack: Standardize positioning for queue indexes (e.g., #05), current status tags (PENDING, CONFIRMED), and historical status markers (PAST) into a predictable flexbox stack in the upper right quadrant.
2. Body Zone & Information Architecture
* Standardize Date-Time: Replace different formatting types with a unified string template: [Icon] Day, DD Month | HH:MM AM/PM — HH:MM AM/PM ([Duration] min).
* Role-Specific Metadata:
    * Clinic Admin View: Displays the operational tracker (🩺 Doctor Name + AWAITING DR. badge) and the tracking anchor (🆔 ID: PAT-0005).
    * Doctor View: Displays location context (🏥 Elite Dental Studio (Kochi)) and clinical indicators (📝 Chief Complaintchips).
3. Action Footer Zone
* Consistent Component Containers: Replace the floating links with structured action footers.
* Clinic Admin Actions: Primary action button for transactional management (Collect Bill) alongside a low-emphasis utility action (Cancel Appointment).
* Doctor Dashboard Actions: Action buttons for healthcare delivery workflows (View Notes and Issue Rx / Records).
