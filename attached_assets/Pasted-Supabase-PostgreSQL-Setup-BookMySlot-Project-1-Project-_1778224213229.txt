Supabase PostgreSQL Setup – BookMySlot Project
1. Project Setup
Platform: Supabase (Postgres‑native backend).
Project Name: bookmyslot-db.
Region: Southeast Asia (Singapore) → closest to Kerala, India.
Tier Used: NANO (Free Tier)
500 MB DB storage.
2 GB bandwidth.
50K monthly active users.
No automatic backups (manual export required).
2. Connection Options
Supabase provides two connection endpoints:
Direct DB Host → db.<project-ref>.supabase.co:5432
Use for psql testing and manual queries.
Works fine with SSL (?sslmode=require).
Pooler Host → aws-1-ap-southeast-1.pooler.supabase.com:6543
Use for ORMs (Drizzle, Prisma).
Requires SNI (Server Name Indication).
psql fails here because it doesn’t send SNI.
3. Environment Variables
Passwords with special characters must be percent‑encoded.
Example: Ultimatix@1234TCS2 → Ultimatix%401234TCS2.
.env example:
env
# For ORM (Drizzle/Prisma)
DATABASE_URL=postgresql://postgres:Ultimatix%401234TCS2@aws-1-ap-southeast-1.pooler.supabase.com:6543/postgres?sslmode=require

# For manual testing with psql
DATABASE_URL_DIRECT=postgresql://postgres:Ultimatix%401234TCS2@db.snwqeckizuemnvpvrxrp.supabase.co:5432/postgres?sslmode=require
4. Drizzle Config
ts
import { defineConfig } from "drizzle-kit";
import * as dotenv from "dotenv";

dotenv.config();

export default defineConfig({
  out: "./migrations",
  schema: "./shared/schema.ts",
  dialect: "postgresql",
  dbCredentials: {
    url: process.env.DATABASE_URL!, // use pooler host

5. Issues Encountered & Fixes
❌ Issue 1: SELF_SIGNED_CERT_IN_CHAIN during migrations
Cause: Supabase requires SSL, pg driver rejects cert.
Fix: Run migrations with:
bash
NODE_TLS_REJECT_UNAUTHORIZED=0 npm run db:push
✅ Worked for local dev.
❌ Issue 2: ENOIDENTIFIER when using pooler with psql
Cause: Pooler requires SNI, psql doesn’t send it.
Fix: Use direct DB host for psql testing:
bash
psql "postgresql://postgres:Ultimatix%401234TCS2@db.snwqeckizuemnvpvrxrp.supabase.co:5432/postgres?sslmode=require"
❌ Issue 3: Runtime 500 errors in Express app
Cause: pg client rejected Supabase’s cert.
Fix: Add SSL config in app code:
ts
import { Pool } from "pg";
const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  ssl: { rejectUnauthorized: false },
});
6. Best Practices for Future
✅ Use pooler host for ORMs, direct host for testing.
✅ Always encode special characters in passwords.
✅ Add ?sslmode=require to connection strings.
✅ In production, configure ssl: { rejectUnauthorized: false } in pg/Drizzle client.
❌ Don’t rely on NODE_TLS_REJECT_UNAUTHORIZED=0 globally in production.
✅ Upgrade to Pro Tier for automatic backups and better reliability.
✅ Monitor resource usage (CPU, RAM, Disk, Connections) in Supabase dashboard.
